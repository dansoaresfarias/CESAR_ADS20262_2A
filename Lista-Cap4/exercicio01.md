# Exercicio 01

a. if (x = 0) usa um sinal de igual só, isso é atribuição e não comparação. O valor 0 é atribuído a x, e o valor da expressão passa a ser 0, que o if trata como falso. Então o bloco do if não executa, e x fica valendo 0 depois disso, não importa o que x tinha antes.

b. Dentro de um if, qualquer valor numérico diferente de zero, seja inteiro ou real, é tratado como verdadeiro. O valor zero é tratado como falso. Não existe um tipo booleano separado em C, o que vale é só o valor numérico.

c. if (x = -5) atribui -5 a x, e o valor da expressão é -5. Como -5 é diferente de zero, a condição é verdadeira, então o bloco do if executa. No final x fica valendo -5.
